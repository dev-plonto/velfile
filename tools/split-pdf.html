How to split a PDF

  1. Choose a PDF.
  2. Type the pages you want, like 1-3, 5, 8-10, or use Quick pick.
  3. Press Extract pages, then Download PDF.

Common questions

Can I change the page order?

Yes. Pages are taken in the order you type them, so 5, 1 starts with page 5.

Does the original change?

No. You get a new PDF and the original file stays as it is.

Is my file uploaded?

No. The file is processed in your browser on your device and is not sent to a server.
