How it works

Three steps. No account, no settings you don't need. Whenever possible, files are processed in your browser instead of being sent to a server.

  1. Choose a tool

    Start from the list above, or drop a file and we suggest tools that fit it.

  2. Add your file

    Set the one or two options that matter. Nothing else to fill in.

  3. Download

    Save the result to your device.

Questions

Are my files uploaded anywhere?

Whenever possible, your files are processed directly in your browser and are not sent to a server.

Do I need an account?

No. Every tool works without signing up.

Which file types can I use?

Images in JPG, PNG and WEBP format, and PDF documents.

Is there a file size limit?

Yes. Images can be up to 50 MB and PDFs up to 100 MB each. Larger files can overload your browser, especially on a phone.

Does it work on my phone?

Yes. Velfile runs in any modern mobile browser.
