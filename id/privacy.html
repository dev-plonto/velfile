Privasi

Apa yang Velfile lakukan dengan file dan datamu.

File kamu tetap di perangkatmu

Alat-alat Velfile (Kompres Gambar, Ubah Ukuran Gambar, Potong Gambar, Konverter Gambar, JPG ke PDF, Gabung PDF, Pisah PDF, Putar PDF, Kompres PDF, dan PDF ke JPG) berjalan di browser kamu. File yang kamu pilih dibaca dan diproses di perangkatmu sendiri. Velfile tidak mengunggahnya ke server dan tidak bisa melihatnya.

Memindahkan file dari halaman utama ke alat

Saat kamu memilih file di halaman utama lalu membuka sebuah alat, file itu disimpan sementara di penyimpanan browsermu agar alat bisa membukanya. Alat menghapusnya begitu file diambil. Kalau kamu tidak jadi membuka alat, salinannya dihapus saat halaman utama Velfile dibuka lagi, atau saat kamu menghapus data situs ini.

Yang tidak dilakukan Velfile

  • Tidak perlu akun atau mendaftar.
  • Velfile tidak memasang cookie sendiri dan tidak memakai analitik.
  • File kamu tidak pernah dipakai untuk iklan. Iklan tidak bisa melihatnya.

Layanan pihak ketiga

Beberapa bagian situs berasal dari perusahaan lain, jadi browsermu terhubung ke mereka saat halaman dimuat:

  • Netlify menjadi tempat situs ini dihosting. Seperti kebanyakan layanan hosting, Netlify bisa menyimpan log teknis seperti alamat IP dan halaman yang diminta.
  • Google Fonts menyediakan huruf, dimuat dari server Google.
  • Google AdSense menayangkan iklan (lihat bagian Iklan di bawah).
  • cdnjs menyediakan library yang dipakai alat PDF (pdf-lib, pdf.js, dan JSZip). Hanya library-nya yang dimuat dari sana. File kamu tidak dikirim.

Iklan

Velfile menampilkan iklan dari Google AdSense. Google dan mitranya dapat memakai cookie atau teknologi serupa untuk menampilkan iklan berdasarkan kunjunganmu ke situs ini dan situs lain. Ini terpisah dari file kamu, yang tetap ada di perangkatmu. Kamu bisa mengatur iklan yang dipersonalisasi di Setelan Iklan Google, atau baca selengkapnya di cara Google memakai data dari situs yang menggunakan layanannya.

Perubahan

Kalau Velfile menambah analitik atau hal lain yang mengubah halaman ini, halaman ini akan diperbarui. Ada pertanyaan? Lihat halaman Kontak.
