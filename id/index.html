Pilih alat

Setiap alat punya satu tugas, dikelompokkan menurut jenis file.

Cara kerja

Tiga langkah. Tanpa akun, tanpa pengaturan yang tidak perlu. Sebisa mungkin, file diproses di browser kamu dan tidak dikirim ke server.

  1. Pilih alat

    Mulai dari daftar di atas, atau letakkan file dan kami sarankan alat yang cocok.

  2. Tambahkan file

    Atur satu atau dua pilihan yang penting. Tidak ada yang lain untuk diisi.

  3. Unduh

    Simpan hasilnya ke perangkatmu.

Pertanyaan

Apakah file saya diunggah ke suatu tempat?

Sebisa mungkin, file kamu diproses langsung di browser dan tidak dikirim ke server.

Apakah saya perlu akun?

Tidak. Semua alat bisa dipakai tanpa mendaftar.

Jenis file apa yang bisa dipakai?

Gambar berformat JPG, PNG, dan WEBP, serta dokumen PDF.

Apakah ada batas ukuran file?

Ada. Gambar maksimal 50 MB dan PDF maksimal 100 MB per file. File yang lebih besar bisa membebani browser, terutama di HP.

Apakah bisa dipakai di HP?

Bisa. Velfile berjalan di browser HP modern mana pun.
