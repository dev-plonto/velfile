Cara mengompres PDF

  1. Pilih PDF.
  2. Pilih tingkat kompresi. Seimbang cocok untuk kebanyakan file.
  3. Tekan Kompres PDF, lalu unduh file yang lebih kecil.

Pertanyaan umum

Apakah teksnya masih bisa dipilih?

Tidak. Tiap halaman disimpan sebagai gambar, jadi teks tidak bisa lagi dipilih, disalin, atau dicari. Simpan file aslinya kalau kamu butuh itu.

Kenapa PDF saya tidak jadi lebih kecil?

PDF yang isinya kebanyakan teks sudah kecil, dan mengubahnya jadi gambar bisa membuatnya lebih besar. Kalau itu terjadi, Velfile memberi tahu kamu dan tidak menawarkan unduhan.

Berapa halaman yang bisa dikompres?

Sampai 100 halaman sekaligus. Untuk PDF yang lebih panjang, pisahkan dulu dengan Pisah PDF.

Apakah file saya diunggah?

Tidak. File diproses di browser di perangkatmu dan tidak dikirim ke server.
