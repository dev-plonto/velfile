Cara memisah halaman PDF

  1. Pilih PDF.
  2. Ketik halaman yang kamu mau, seperti 1-3, 5, 8-10, atau pakai Pilih cepat.
  3. Tekan Ambil halaman, lalu Unduh PDF.

Pertanyaan umum

Bisakah urutan halamannya diubah?

Bisa. Halaman diambil sesuai urutan yang kamu ketik, jadi 5, 1 dimulai dari halaman 5.

Apakah file aslinya berubah?

Tidak. Kamu mendapat PDF baru, dan file aslinya tetap seperti semula.

Apakah file saya diunggah?

Tidak. File diproses di browser di perangkatmu dan tidak dikirim ke server.
