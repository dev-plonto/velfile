Cara mengubah PDF jadi JPG

  1. Pilih PDF.
  2. Kosongkan Halaman untuk semua halaman, atau ketik rentang seperti 1-3, 5. Pilih kualitas gambar.
  3. Tekan Ubah ke JPG, lalu unduh tiap halaman atau semuanya sebagai ZIP.

Pertanyaan umum

Berapa halaman yang bisa diubah sekaligus?

Sampai 50 halaman. Untuk PDF yang lebih panjang, ubah satu rentang demi satu rentang.

Kenapa PDF saya tidak bisa dibuka?

PDF yang dikunci dengan kata sandi tidak bisa dibaca. Hapus kata sandinya dulu.

Apakah file saya diunggah?

Tidak. File diproses di browser di perangkatmu dan tidak dikirim ke server.
