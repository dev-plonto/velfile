Cara mengompres gambar

  1. Pilih gambar (JPG, PNG, atau WEBP), atau letakkan di kotak.
  2. Geser Kualitas. Kualitas lebih rendah membuat file lebih kecil, dan hasilnya langsung diperbarui.
  3. Lihat ukurannya, lalu tekan Unduh.

Pertanyaan umum

Kenapa PNG saya tidak mengecil?

PNG menjaga semua detail, jadi kualitasnya tidak bisa dikurangi. Simpan sebagai JPG atau WebP untuk file yang jauh lebih kecil.

Kualitas berapa yang sebaiknya dipilih?

Sekitar 70 sampai 80 persen biasanya terlihat sangat mirip dengan aslinya, tapi ukurannya jauh lebih kecil.

Apakah gambar saya diunggah?

Tidak. Gambar diproses di browser di perangkatmu dan tidak dikirim ke server.
