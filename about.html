About

Simple file tools that run in your browser.

What Velfile is

Velfile is a small set of tools for everyday files, free to use. You can compress, resize, crop and convert images, and merge, split, rotate, compress and convert PDFs. Each tool does one job and opens ready to use, with no account and no sign-up.

How it works

The tools run in your browser. When you choose a file, it is read and processed on your own device, and Velfile does not upload it to a server. The Privacy page explains this in more detail.

Good to know

  • Images can be up to 50 MB and PDFs up to 100 MB.
  • Some PDF tools work on a limited number of pages at a time. Each tool says so on its page.
  • Compress PDF turns each page into an image, so the text can no longer be selected or searched.
  • Speed depends on your device, because the work happens there.

Who makes it

Velfile is an independent project. Found a bug, or want a tool added? Write to the address on the Contact page.
